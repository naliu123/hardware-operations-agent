# 将增量正文作为可撤回草稿，最终答案仍经过完整复核

聊天工作台需要模型边生成边显示正文，而原问答实现等待完整结构、引用和设备
快照复核后才发布答案。采用用户确认的草稿/最终答案区分：真正的模型增量先以
草稿展示，完整复核后提交最终答案，失败或修正时撤回对应草稿版本。

这会将“复核前不展示正文”改为“复核前明确展示为草稿”，保留最终答案的引用与
业务校验。事件持久化、重连、历史搜索和摘要都必须理解草稿版本及撤回，不能把
曾经可见的正文误当作已确认历史。见[规格](../design/chat-workbench-spec.md)和
[技术设计](../design/chat-workbench-technical-design.md)。

WB-05 已完成持久化草稿版本、真实增量、撤回、原子终态和重连验收；WB-07 已完成
对应浏览器状态与安全 Markdown 展示。
