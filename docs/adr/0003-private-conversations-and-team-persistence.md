# 团队工作台以账号归属和 PostgreSQL 持久化私有会话

原系统使用共享本地操作者令牌，不能表达用户间私有数据隔离。团队工作台采用
用户确认的管理员开通账号、用户名密码登录和 PostgreSQL 业务存储，会话、附件
及产物属于确定用户和会话；管理员管理账号不意味着可以阅读其他人的私有聊天。

原有单操作者模式保留在独立运行模式中，团队模式拒绝共享令牌绕过。旧记录须
显式映射归属，不能默认公开。文件保存在受控持久化目录，经授权读取；聊天附件
不进入公共知识索引，知识库管理另行交付。

这增加了迁移和所有读取路径上的归属校验，也意味着事件流、下载、搜索及缓存
都必须按同一作用域控制。见[技术设计](../design/chat-workbench-technical-design.md)。
WB-01 至 WB-08 已完成迁移、归属、真实 PostgreSQL、跨浏览器、备份恢复及两用户
隔离验收。
