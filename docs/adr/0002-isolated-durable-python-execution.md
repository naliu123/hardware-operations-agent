# Python 使用独立隔离执行和持久化身份，重启不自动重跑

模型可自动运行 Python 分析私有附件，但代码不能获得应用凭据、宿主文件或其他
会话数据。采用用户确认的独立 Linux + gVisor 沙箱、无网络、全新进程和固定资源
配额，代码与文件持久化，解释器变量不跨执行保留；隔离不可用时拒绝执行。

每次执行先持久化独立身份、输入和预算，再由 runner 幂等受理。浏览器断线不取消
任务，显式停止终止本轮执行；服务重启后未完成任务标记中断，由用户新建重试。
这放弃自动恢复同一 Python 内核和重跑整个问答图的便利，换取可核对的执行记录、
明确的失败语义与跨用户隔离。不能借用现有问答恢复行为自动重复执行代码。

实际隔离验收需要 Linux 环境，协议桩不证明 gVisor 或资源限制有效。见
[技术设计](../design/chat-workbench-technical-design.md)。WB-03 已在实际 Linux +
gVisor 环境完成持久身份、资源限制、取消和重启回收验收；模型自动调用在 WB-06 接入。
