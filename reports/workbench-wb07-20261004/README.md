# WB-07 验收记录

日期：2026-10-04。Claude 风格中文聊天工作台的完整状态、长内容、安全渲染、
键盘操作和窄屏布局已通过真实浏览器验收。

## 实现

- 保留暖白、低饱和与宽松排版，引入中性白和灰绿表面，减少单一米色层次。
- 左侧会话、搜索、账号入口，中间消息/附件/流式草稿，来源抽屉、执行卡及产物
  均使用同一响应式界面；390 px 下侧栏折叠，标题和会话操作不重叠。
- 操作字符替换为 Lucide 图标，并保留可访问名称、键盘焦点和文字命令。
- 表单卡片、模态与重复项目圆角不超过 8 px；消息气泡和输入框保留交互形态圆角。
  全局字距为 0。
- 长问题自动换行；长文件名稳定省略；长代码保留独立横向滚动，不造成页面级横向
  溢出。
- Enter 发送，Shift+Enter 换行；登录凭据被撤销后，下一次 API 请求统一清除 CSRF
  与页面会话并返回登录页。
- `SafeMarkdown` 跳过 HTML，不创建模型给出的图片节点或链接节点。来源与产物只通过
  应用生成的受保护同域路径展示。

## 浏览器验收

Playwright/Chrome 通过 4/4：

1. 登录、账号、会话、搜索、跨浏览器恢复、停止、重试、删除和实时草稿。
2. 图片选择/粘贴、PDF/日志拖拽、部分解析、页码/行号和来源预览。
3. 实际 Linux/gVisor Python 执行状态、代码、stdout、CSV 与 PNG 产物。
4. 超长问题、超长文件名、1200 字符代码行、恶意 Markdown、键盘提交和过期登录。

恶意回答包含外链图片、外链链接和 `script`。浏览器断言：

- 未创建外链 `img` 或 `a`；
- 未向测试外部域发起请求；
- 脚本变量未执行；
- 文档宽度未超过视口。
