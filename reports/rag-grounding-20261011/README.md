# 在线答案原文支撑复核验收

对应 [03i 工单](../../.scratch/hardware-operations-agent/issues/03i-online-answer-grounding.md)。
实现为 Go + Eino，接入现有在线 `validate`。LIVE 默认执行无工具语义复核，复核器
可单独配置，默认与生成器使用同一模型。REPLAY 默认保留既有摘录与协议回放。

## 行为与证据

- 逐条检查结论是否由实际引用的原文支持；SUPPORTED 必须提供精确匹配来源行范围的
  摘录。合法引用但错误结论不能直接发布；格式、引用和语义修正共享一次机会。
- 修正后仍不支持时，保留独立成立的已通过结论并报告有界缺口；全部不支持则
  UNRESOLVED。服务故障、上游超时和预算耗尽不放行。
- 复核结果每次完成即持久化，绑定输入结论、输入哈希、原文哈希、判定与实际用量。
  在修正过程中停机，重启后已有记录仍可回读。
- 草稿在复核完成前不定稿，失败或修正时撤回。最终答案事务再核对知识发布状态和
  设备快照；资料在复核期间撤回不能成为当前指导。
- 私有日志和 PDF 页文本保留原来源身份，参与混合结论复核；原文缺失的视觉描述
  不单独证明像素事实。调用证据工具后不能通过 reply 字段绕过事实门禁。

公开 HTTP 回归见 [答案验收测试](../../test/acceptance/answer_grounding_test.go)、
[工作台验收测试](../../test/acceptance/workbench_grounding_test.go)。
业务存储为真实临时文件或 PostgreSQL；仅外部模型与附件解析依赖使用确定性协议桩，
结果均为 REPLAY，未用于宣称真实模型语义准确率。

## 验证结果

已通过门禁专项回归、真实临时 PostgreSQL/SSE、复核审计重启、PDF/日志混合来源、
错误引用/摘录/范围、漏判、非法结构、工具调用、上游超时、输入超预算与缺口限额。
`go vet ./...`、后端构建与 diff 格式检查通过。

最终全量 `./scripts/go.sh test -race ./... -count=1` 通过：acceptance 362.296 秒，
contracts 4.706 秒，真实临时 PostgreSQL 已配置；未配置的实际沙箱/ES 专项按既有
规则跳过，不计为本次接入验收。最后长理由保留修复通过针对性 race 回归、vet、
构建与差异检查。现有持续预览服务未替换，本次交付为源码与验证。

审查期间修复了以下问题，并加入公开 HTTP 回归：停机前已完成的复核必须立即落库；
复核、监控及模型缺口合并后仍遵守 12 项/2000 字节上限；澄清字段不能承载已被拒绝
的事实结论；PDF 零行号来源使用页内范围；上游 504 独立分类；空完成报告用量须
保留；撤回后回答所属用户仍可读取审计出处，其他用户保持 404。

保持 Go/Eino、真实业务存储、外部协议回放标注、所属用户限制及事务提交规范。

## 真实模型接入

`TestLiveMainAgentKnowledgeTool` 通过真实 `deepseek-v4.1-flash`、公开 HTTP、
隔离临时文件存储与合成手册完成问答。最终复验：ANSWERED，1 次知识工具，
4 次返回 usage 的模型调用，共 7129 tokens，1 次原文支撑复核；测试耗时 6.68 秒。

一次复验曾因生成输出未通过格式/引用校验返回 INVALID_MODEL_OUTPUT，答案未发布。
同步证据工具调用后的回复规则与修正提示后再次通过；该失败保留，不记为成功样本。

该烟测只证明真实模型协议和原文复核接入，不代表 CCE 全量语义准确率、生产设备或
运维专家验收。默认生成器和复核器为同一模型，存在相关偏差；精确摘录校验无法
独立证明自然语言语义蕴含。Phoenix 在本次未启用远端收集，代码提供 EVALUATOR
trace 与既有隐私过滤，没有宣称本次结果已同步 Phoenix。
