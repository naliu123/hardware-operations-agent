# 04: QA-04 查询设备当前状态并说明数据范围

**Task:** QA-04

**Blocked by:** 02 (QA-02)

**Status:** ready-for-agent

**Spec:** [总体设计](../../../docs/design/hardware-operations-agent-overall-design.md) · [Go + Eino 技术设计](../../../docs/design/hardware-operations-agent-technical-design.md)

**交付行为：** 用户询问设备状态时，通过监控适配器获取告警、必要指标及相关日志，返回有时间和范围的摘要。

**验收条件：**

- [ ] 实时与回放适配器遵循相同结果语义，响应明确标记数据模式。
- [ ] 查询失败、无记录、部分数据、过期和能力不支持分别体现。
- [ ] 运行数据、设备映射、时间窗口和单位可从答案追溯。
- [ ] 只查到部分正常指标时不会宣称整台设备正常。
- [ ] 对错设备、错时间窗口和已过期的缓存有反例验证。
