# 03f: CCE RAG 表格与图片专项处理

**Task:** CCE-RAG-MULTIMODAL-ASSETS

**Blocked by:** 03d（已完成）

**Status:** done

## 交付行为

在不修改引用原文的前提下，为 CCE 手册建立表格与图片专项预处理：

1. 说明型表格按原始数据行拆分，由 LLM 重写为自包含段落；数据型表格由 LLM
   生成保留对象、指标、单位、范围和关键值的摘要。
2. 图片由支持视觉输入的模型读取，生成只描述可见内容的文本；描述插入图片原始
   位置之后供拆分、召回与回答使用，Markdown 图片标记仍保留在引用原文中。
3. embedding 输入移除图片 URL、Markdown 链接目标和结构符号噪声；不可变原文、
   行号与内容哈希不变。
4. 表格改写、表格摘要、图片描述分别作为 nested 检索表示绑定原片段，命中后
   返回包含原始表格或图片标记的原文。
5. 建立独立的表格/图片开发集和保留验收集，开发集按 bad case 迭代；最终配置
   冻结后只运行一次保留集。

## 约束

- 视觉模型必须实际接收图片，不允许仅依据 URL、标题或相邻文字声称看过图片。
- 表格改写不得删除或修改不可变原文，不得把模型生成文本作为引用事实。
- 每个派生表示记录对应原文行范围；图片描述必须覆盖每个图片位置。
- 图片下载或模型失败必须显式失败并保留 checkpoint，不静默退回纯文本描述。
- 新索引和评测产物使用独立版本，不覆盖 v1/v2 及历史评测结果。
