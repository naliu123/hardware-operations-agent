# 14: PF-02 128/256 活跃诊断容量评估

**Task:** PF-02

**Blocked by:** 13 (PF-01)

**Status:** ready-for-agent

**Spec:** [总体设计](../../../docs/design/hardware-operations-agent-overall-design.md) · [Go + Eino 技术设计](../../../docs/design/hardware-operations-agent-technical-design.md)

**交付行为：** 对问答和诊断混合负载、集中告警及大量挂起任务唤醒进行容量测试。

**验收条件：**

- [ ] 分别测试 128 和 256 个集群活跃诊断，记录设备数、归并后到达率与自动排查时长。
- [ ] 单独测量模型调用并发、token 吞吐、工具查询和下游限流。
- [ ] 后台负载下普通问答仍有预留资源，记录实际延迟分布。
- [ ] 挂起任务不占活跃额度，多个 worker 的额度总和符合配置。
- [ ] 模型、监控接口或硬件不足时报告实际瓶颈和可支撑容量，不直接宣布十万卡目标已达成。
