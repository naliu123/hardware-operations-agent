# 12: HC-01 现场检查、跨班次继续与恢复观察

**Task:** HC-01

**Blocked by:** 08 (DX-02)

**Status:** ready-for-agent

**Spec:** [总体设计](../../../docs/design/hardware-operations-agent-overall-design.md) · [Go + Eino 技术设计](../../../docs/design/hardware-operations-agent-technical-design.md)

**交付行为：** 将远程无法完成的检查交给人员，接收文字、照片或测量结果，恢复诊断并按故障类型验证恢复。

**验收条件：**

- [ ] 任务包含设备和部件位置、方法、观察要求及停止条件。
- [ ] 反馈附带目标、时间、单位和人员；错误任务或设备的反馈不进入当前证据。
- [ ] 等待期间挂起，独立分支仍可执行；跨对话恢复时刷新必要上下文。
- [ ] 照片推断保留适用范围，不把不可见状态写成确定事实。
- [ ] 观察窗口由定时任务推进，根因未知但已恢复等组合状态可以表达。
