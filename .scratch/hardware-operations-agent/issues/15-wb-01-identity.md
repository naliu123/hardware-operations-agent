## 交付行为

增加 React + TypeScript + Vite 构建入口，由 Go 同域托管最小登录、账号管理和聊天页。
实现 `users` 模式、管理员引导与账号管理、会话凭据和 PostgreSQL 用户归属。
通过既有模型 Adapter 完成登录 → 建立会话 → 提问 → 读取回答的完整流程。

梳理所有既有入口：团队模式拒绝共享令牌，公共知识写入等操作限管理员；
尚无归属的旧诊断入口默认关闭。保留独立 `local_token` 模式的回放与 CLI。
为已有数据库引入可验证迁移和显式历史归属映射，不自动公开旧记录。

## 验收条件

- [x] 两普通用户和一管理员通过真实 HTTP 登录、退出、停用及凭据重置。
- [x] 私有会话、响应、事件和引用读取交换 ID 后不能越权；管理员无他人私有聊天读取权。
- [x] 伪造请求中的 owner、共享令牌和绕过前端的请求不能获得额外权限。
- [x] Cookie、CSRF、会话撤销、登录限制及认证错误语义通过实际请求验证。
- [x] 使用真实临时 PostgreSQL 验证迁移、重启、旧记录未映射及显式映射行为。
- [x] 浏览器完成最小知识问答；确定性外部模型标为 REPLAY，真实模型结果单列。
- [x] 原有 `local_token` 公共 HTTP 回归与前端构建通过。
