# 13: PF-01 三类诊断路径的历史回放

**Task:** PF-01

**Blocked by:** 09 (EV-01), 11 (EX-02), 12 (HC-01)

**Status:** ready-for-agent

**Spec:** [总体设计](../../../docs/design/hardware-operations-agent-overall-design.md) · [Go + Eino 技术设计](../../../docs/design/hardware-operations-agent-technical-design.md)

**交付行为：** 以明确错误码、拓扑关联、现场协作案例评测完整诊断，保留每次计划变化与证据。

**验收条件：**

- [ ] 运行数据、知识与历史工单均受回放时间和案例血缘约束。
- [ ] 最终维修结论、后续材料及其重复副本仅供评分侧使用。
- [ ] 缺少检查记录时返回缺失，回放不会执行生产设备命令。
- [ ] 统计根因命中率、错误确认比例、覆盖率、检查有效性和定位耗时。
- [ ] 多根因、无足够证据和型号版本不匹配的案例单独分析。
