## 交付行为

将受控的附件读取与 Python 执行工具注册到现有 Eino 主 Agent。模型选择代码和输入
文件 ID，用户、会话、路径、运行时与权限由可信上下文决定。每轮 Python 最多三次，
失败重试也计数，总时限与已有知识工具预算分别校验。

消息卡片显示真实执行状态、代码、输出和产物；图表可预览，结果文件可下载。
后续问题能将完成产物作为只读输入。计算结论关联实际执行和输入；附件与公共知识
冲突显示来源和差异。执行成功不替代分析方法与设备判断的复核。

## 验收条件

- [x] 通过浏览器与公开 HTTP 上传日志，模型自动调用真实沙箱统计、绘图并提供结果文件。
- [x] 追问使用前轮产物重新分组/绘图；新进程中无旧变量，跨会话无法引用旧文件。
- [x] 工具参数中伪造 owner、宿主路径、网络、镜像或资源配置均被拒绝。
- [x] 三次调用限制覆盖代码自动修正与失败；五分钟总预算包含排队和重试。
- [x] 明确区分模型预期输出、运行日志、不完整结果和成功产物；引用回到实际执行记录。
- [x] 停止实际终止执行；断线继续；服务重启不重跑；显式重试关联旧响应。
- [x] 删除期间的运行、上传及产物回传最终被清理，私有内容不进入公共索引或共享追踪。
- [x] 真实模型 + 真实图片/PDF/日志 + 实际 Linux 沙箱联调与确定性 REPLAY 分别留证。
