# 01: QA-01 从已发布知识得到带引用的回答

**Task:** QA-01

**Blocked by:** None

**Status:** done

**Spec:** [总体设计](../../../docs/design/hardware-operations-agent-overall-design.md) · [Go + Eino 技术设计](../../../docs/design/hardware-operations-agent-technical-design.md)

**交付行为：** 导入一份资料，经发布后提交问题，取得答案并打开对应原文。以 Go 实现最小 HTTP 会话入口、知识修订、检索与模型适配器及结果持久化，通过 Eino Graph/Chain 串起召回、生成和校验。

本任务同时初始化 Go 工程、锁定兼容的 Eino 依赖，并通过确定性 ChatModel 与 Retriever 实现打通 Eino 调用。数据库访问和迁移沿用技术设计的 Go 配套默认值。

先以可提取文本和已复核内容建立流程；PDF 文本提取接入后必须保留章节、页码和命令上下文，扫描或解析失败资料明确返回待处理状态。

**验收条件：**

- [x] 未发布资料不会进入可用答案依据；已发布片段可以回到确切修订和原文位置。
- [x] 回答的核心结论关联实际召回片段，不能引用不存在的片段。
- [x] 配置方法仅作为指导输出，问答入口不下发设备命令。
- [x] 模型接口不可用时返回明确错误，不用固定答案冒充模型成功。
- [x] 本地确定性数据可完成请求到结果的集成验证；真实模型验证结果单独记录。
- [x] Go 工程可构建，Eino 问答图可编译并被集成测试实际调用，`go test ./...` 通过。

## 交付与验证记录（2026-09-19）

- Go 1.26.8 / darwin arm64；锁定 Eino v0.9.19、pgx/v5 v5.7.6。提供 `cmd/hwopsd` 与 `cmd/hwops-demo`。
- Eino Graph 实际执行召回、生成和校验，模型输出允许一次修正；资料仅限已发布 `GENERAL`，引用携带修订、章节、行号、内容哈希和原文地址。
- 文件存储通过真实 HTTP 验证持久化、撤回后的历史引用读取、处理中断后恢复；PostgreSQL 适配器及幂等初始建表 SQL 已构建。
- `HWOPS_KEEP_TEST_ARTIFACTS=1 ./scripts/go.sh test -work -race ./... -count=1 -timeout=60s -v` 通过：10 个顶层测试通过，PostgreSQL 集成测试因未配置专用数据库跳过。
- `./scripts/go.sh vet -work ./...`、`./scripts/go.sh build -work -o bin/ ./cmd/...` 完成。沙箱禁止清理临时目录，`-work` 和测试环境变量用于保留产物，不改变业务断言。
- 实际启动编译后的服务和演示客户端，成功完成发布、提问与原文读取；验证服务重启后答案仍可读取，以及未配置模型的 LIVE 服务返回 `MODEL_UNAVAILABLE`。演示进程已停止。
