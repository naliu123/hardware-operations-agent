# 03: QA-03 召回不足时纠偏，资料冲突时说明缺口

**Task:** QA-03

**Blocked by:** 02 (QA-02)

**Status:** ready-for-agent

**Spec:** [总体设计](../../../docs/design/hardware-operations-agent-overall-design.md) · [Go + Eino 技术设计](../../../docs/design/hardware-operations-agent-technical-design.md)

**交付行为：** 通过 Go 检索适配器与 Eino Retriever 接口完成词项与向量两路召回及排名融合，在有预算的情况下调整查询，并对发布状态、适用性和引用做复核。

**验收条件：**

- [ ] 错误码精确查询、症状同义表达和父章节扩展均有验证样本。
- [ ] 初次未匹配时至少验证一种有效检索纠偏；重复等价查询不会空转。
- [ ] 不适用版本即使相关性高，也不会被选为当前操作依据。
- [ ] 撤回资料不用于新答案；冲突资料保留出处并暂停受影响建议。
- [ ] 记录查询、索引代次和候选过滤原因，可区分未召回、未入库与未知适用性。
