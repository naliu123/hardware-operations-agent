# 08: DX-02 并行检查、重复事件和中断恢复

**Task:** DX-02

**Blocked by:** 07 (DX-01)

**Status:** ready-for-agent

**Spec:** [总体设计](../../../docs/design/hardware-operations-agent-overall-design.md) · [Go + Eino 技术设计](../../../docs/design/hardware-operations-agent-technical-design.md)

**交付行为：** 多个独立检查可以并行，计划修订与迟到结果可以共存，Go worker 中断后依据业务状态与 Eino 检查点恢复正确状态。实现 PostgreSQL `CheckPointStore` 适配及运行、图版本、检查点映射。

**验收条件：**

- [ ] 两个 worker 使用旧版本提交时，只有合法版本更新被接受。
- [ ] 重复事件不重复应用；迟到结果归入原步骤并接受当前适用性判断。
- [ ] outbox 补发、Eino 恢复时节点重入不会生成重复业务操作。
- [ ] 多个等待理由同时存在，任一有效反馈可以推进相关分支。
- [ ] 挂起释放活跃额度；恢复不重置预算、不清空证据历史。
- [ ] 覆盖跨 worker 恢复、检查点落后及图版本不兼容，状态以业务记录为准；相关并发测试通过 `go test -race`。
