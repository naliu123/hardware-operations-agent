# 18: WB-04 私有多模态附件与来源

**目标：** 用户上传、预览并引用当前会话中的图片、文字版 PDF 和文本日志。

**Blocked by:** 16 (WB-02), 17 (WB-03)

**Status:** done

**依据：** [规格](../../../docs/design/chat-workbench-spec.md) R15～R19；
[技术方案](../../../docs/design/chat-workbench-technical-design.md)第 9 节。

## 交付行为

实现粘贴、拖拽、上传、解析状态与授权预览/下载。保存不可变原文件和逐页/逐行
来源，图片使用实际字节做视觉理解，文字版 PDF 保留页码及页内图片/表格。
纯扫描 PDF 明确不支持；部分解析记录成功范围和具体缺口。

每消息 5 个文件、单文件 50 MB、合计 100 MB、PDF 200 页；服务端检查真实内容与
引用总量。解析用有界隔离任务。会话文件不写入公共 ES 索引，提供有界私有
页/片段读取及 SourceRef，支持只依据私有材料回答。

## 验收条件

- [x] 浏览器粘贴图片、拖拽 PDF/日志，显示上传和解析进度并定位原图、页码、行号。
- [x] 数量、字节数、页数边界及超限均通过公开 HTTP 测试；伪造 MIME/长度不能绕过。
- [x] 图片字节、PDF 表格与内嵌图片实际进入对应处理路径，原文与引用哈希不被增强改写。
- [x] 扫描件、混合页、损坏文件、解析超时、解码/展开超限明确反馈，不静默忽略。
- [x] 部分成功只允许显式使用可用范围；模型及答案保留未读取页面的缺口。
- [x] 两用户、同用户两个会话交换附件 ID 后，读取、引用、Range 预览和工具输入均拒绝越权。
- [x] 上传半途退出、删除时解析完成、迟到产物与清理失败均不泄露或复活文件。
- [x] 真实临时存储与实际解析程序验收；视觉模型外部桩和真实视觉调用分别记录。
