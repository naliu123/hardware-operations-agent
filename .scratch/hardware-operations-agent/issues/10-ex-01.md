# 10: EX-01 当前对话用户审核动态 CLI 与变更

**Task:** EX-01

**Blocked by:** 08 (DX-02)

**Status:** ready-for-agent

**Spec:** [总体设计](../../../docs/design/hardware-operations-agent-overall-design.md) · [Go + Eino 技术设计](../../../docs/design/hardware-operations-agent-technical-design.md)

**交付行为：** 主 Agent 生成具体操作，用户查看原因与手册出处后决定，执行结果返回诊断流程。Eino 工具封装调用 Go 操作模块，Graph 等待或中断恢复必须经过业务审批校验。

**验收条件：**

- [ ] 动态生成的查询 CLI 与状态变更均需审核，已接入只读工具可自动调用。
- [ ] 审批展示目标、完整操作、原因及出处；没有手册依据时如实标记。
- [ ] 审核用户来自当前处理对话的认证身份，不能通过请求体伪造。
- [ ] 同意只改变执行条件，不添加虚构诊断证据；拒绝后不执行。
- [ ] 修改目标、命令或参数形成新的审批对象；按原内容批准的单次操作不被重复下发。
