# 03i：在线答案原文支撑复核

**Task:** ONLINE-ANSWER-GROUNDING

**Blocked by:** 03h、WB-05（均 done）

**Status:** done

## 交付行为

根据 2026-10-11 用户授权，在当前在线 RAG 回答链路加入语义复核。每个知识结论必须由本轮实际引用的原文支持，不能仅凭真实 fragment ID 发布错误结论。沿用 Go + Eino、公开 HTTP 与外部模型 Adapter。

## 契约

- LIVE 默认必须复核；使用独立的无工具模型调用，默认复用生成模型，可显式配置不同复核模型。禁止以模型自报置信度放行。同模型复核的相关偏差须明确记录。
- REPLAY 默认保持既有摘录与协议回放；可显式注入外部 HTTP 复核模型测试门禁，输出仍为 REPLAY，不声称完成真实语义认证。
- 程序提供问题、可信设备上下文、结论及权威原文、目录和来源；复核模型不能把答案自己编写的摘录或检索用候选问题当作证据。
- 对每个结论返回 SUPPORTED、UNSUPPORTED 或 CONTRADICTED。SUPPORTED 必须覆盖整条结论的全部实质性断言，且在删掉其他结论后仍能独立成立；只能由该结论所引用的来源支持，其他已返回来源仅用于核对反证。
- 返回的支持出处、原文范围及摘录须通过程序精确校验；判定缺项、重复、非法 JSON、未知字段、伪造来源/摘录、模型工具调用或不完整输出均明确失败。
- 文本原文是事实依据；表格/图片派生描述标为辅助，不能靠描述单独证明像素中的事实。混合或私有结论复用可信工具返回的内容与来源，不绕过原有私有来源校验。
- 格式、引用及语义修正共用一次机会，修正后重新进行完整复核；仍无支撑时仅保留已通过且可独立成立的结论并返回 PARTIAL，全部不通过返回 UNRESOLVED。复核服务故障、超时、预算耗尽与资料不足分别表达，不能默默放行。
- 模型调用及 HTTP 重试计入现有总时限与调用预算；复核不向页面推送正文或思考。保留已有草稿版本、修正撤回与终态原子提交。
- 响应保存复核版本、输入/结论/证据哈希、逐条判定、可回读支持出处、trace 与实际 usage；失败与重启仍可追溯。
- 最终保存事务再次核对所引用知识仍发布以及当前设备快照；复核期间撤回或设备更新不发布旧结论。
- 不修改入库候选问题生成器、历史评测分数、诊断判据或设备执行权限。
