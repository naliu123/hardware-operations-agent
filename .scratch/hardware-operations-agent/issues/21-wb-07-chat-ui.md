# 21: WB-07 Claude 风格聊天工作台

**目标：** 用户在统一的中文界面中管理会话、提问、上传材料、查看来源与执行产物。

**Blocked by:** 20 (WB-06)

**Status:** done

**依据：** [规格](../../../docs/design/chat-workbench-spec.md)第 4、5 节。

## 交付行为

在前序工单已有可用界面的基础上完成视觉和完整状态：Claude 风格的暖白背景、
低饱和配色、简洁侧栏、宽松排版和圆角输入区。使用本项目名称，桌面为主要场景。
左侧会话列表与搜索，中间消息和附件输入，来源及文件按需展开预览。

统一草稿/最终答案、排队/执行、上传/解析及失败状态。代码、日志、图表和下载
产物与消息关联，管理员有独立账号管理入口。预览和下载使用受保护路径。
