# 19: WB-05 真实增量正文与可撤回草稿

**目标：** 用户在模型生成结束前看到正文增量，复核后得到可追溯的最终答案。

**Blocked by:** 16 (WB-02), 18 (WB-04)

**Status:** done

**依据：** [规格](../../../docs/design/chat-workbench-spec.md) R11～R14；
[技术方案](../../../docs/design/chat-workbench-technical-design.md)第 8 节；
[ADR-0001](../../../docs/adr/0001-provisional-streaming-answers.md)。

## 交付行为

补齐模型 Adapter 的真实 stream 与原生 tool-call 分片处理，Eino 调用实际消费流。
从结构化输出中安全增量提取正文；工具参数与内部 JSON 不展示为答案。
持久化带草稿版本的事件，支持增量、撤回、定稿、取消、中断和重连。

校验知识、附件及执行类型的来源；在最终提交前检查会话、取消、发布状态和设备
快照。工作台每轮总预算五分钟，失败修正不重置预算。重启后的未完成响应标中断，
停止入口持久化取消并向实际调用传播，不自动重跑整张图。

## 验收条件

- [x] 外部模型分块响应尚未结束时，公开 SSE 与浏览器已收到多个真实正文增量。
- [x] JSON/Unicode 任意分片、tool-call 参数分片、异常结束、usage 和流取消正确处理。
- [x] 部分工具参数不能触发工具执行，内部结构与推理内容不泄露到正文。
- [x] 伪造引用、撤回知识、设备更新和输出修正撤回正确草稿版本。
- [x] 断线续读、重复事件、撤回后的旧增量、刷新及重开不会复活草稿或重复提交。
- [x] 最终答案与终态事件原子保存；存储失败不能先向用户承诺定稿。
- [x] 停止、超时、排队和模型重试共用总预算；明确记录取消和中断。
- [x] 真实模型 stream + tool-call 烟测另行通过；固定结果或打字动画不计作流式验收。
