# 07: DX-01 通过实际查询结果推进 Plan–Execute–Replan

**Task:** DX-01

**Blocked by:** 06 (QA-06)

**Status:** in-progress

**Spec:** [总体设计](../../../docs/design/hardware-operations-agent-overall-design.md) · [Go + Eino 技术设计](../../../docs/design/hardware-operations-agent-technical-design.md)

**交付行为：** 提交一个有适用排障方案的错误码事件，以 Eino Graph 的 Plan、Execute、Replan 及校验节点生成计划、执行只读检查，并根据返回结果调整后续计划。

**验收条件：**

- [ ] 保存初始计划、候选原因、依赖和确认条件，步骤目的与实际观察分开记录。
- [ ] 改变检查结果后，后续检查或判断产生符合证据的变化。
- [ ] 就绪步骤只在依赖与前置条件满足时执行；无效计划不能下发。
- [ ] 复用有效证据时保留依据，工具失败不转化为设备故障结论。
- [ ] 根因确认、故障恢复和本次运行完成分别记录；预算耗尽时输出缺口。
- [ ] Eino 图的条件分支实际覆盖继续、等待、暂停和完成，Go 结构化提案通过业务校验后才可提交。
