# 11: EX-02 命令结果不明时核对状态

**Task:** EX-02

**Blocked by:** 10 (EX-01)

**Status:** ready-for-agent

**Spec:** [总体设计](../../../docs/design/hardware-operations-agent-overall-design.md) · [Go + Eino 技术设计](../../../docs/design/hardware-operations-agent-technical-design.md)

**交付行为：** 命令下发前后任意中断，恢复流程保留真实状态，并优先核对设备实际结果。

**验收条件：**

- [ ] 覆盖下发意图入库后、调用设备后和回执入库前中断的情况。
- [ ] 不确定结果标记 `UNKNOWN`，不会仅因重试或重规划重复下发变更。
- [ ] 有远端操作标识时核对原操作；没有时按适配器能力查询实际状态。
- [ ] 迟到回执归入原操作，同设备冲突变更等待核对。
- [ ] 模拟执行验证与真实设备联调记录分开，不把模拟回执记作真实执行成功。
