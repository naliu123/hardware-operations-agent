# 03d: CCE RAG语义拆分与多问题召回

**Task:** CCE-RAG-SEMANTIC-ENRICHMENT

**Blocked by:** 03b（已完成）

**Status:** done

## 交付行为

为CCE全目录建立新的RAG索引版本：

1. 对每篇文档标题下的正文使用LLM决定语义片段边界，片段正文必须仍是可核对的原文连续行。
2. 表格和图片生成额外的检索描述；图片描述只基于图片标题、URL和相邻原文，不声称读取了当前模型不可见的像素内容。
3. 每个片段由LLM从多个角度生成多个可能回答的问题，每个问题单独向量化并绑定回原始片段。
4. 用户问题由LLM改写为多个相近问题，保留原问题并执行多路并行召回，融合后只返回原始片段。
5. 新索引完成后只运行一轮纯RAG检索评测，不运行答案生成或答案评审。

## 约束

- 旧`hwops-cce-manual-v1`索引和历史评测结果保持不变；新能力通过显式配置启用。
- LLM拆分只返回原文块范围，不允许改写引用正文；所有范围、哈希和问题/描述数量在入库前验证。
- 表格、代码和图片Markdown不在任意字节位置截断；超长表格按完整行分组。
- 正文、每个候选问题、每个表格描述和每个图片描述分别生成向量，同一片段的多向量命中归并为一个结果。
- 问题改写失败时返回明确错误，不静默退回旧流程并把结果冒充优化配置。
- 全量预处理和入库具备内容哈希、提示哈希及逐文档checkpoint。
