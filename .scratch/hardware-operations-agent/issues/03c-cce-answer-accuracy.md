# 03c: CCE全目录问答评测与准确率迭代

**Task:** CCE-ANSWER-ACCURACY

**Blocked by:** 03b（已完成）

**Status:** in-progress

## 交付行为

基于已入库的641篇CCE用户指南，建立有来源、原文证据、参考答案及必答要点的问答评测集，运行真实模型问答，记录每轮bad case、根因、优化方向、改动与前后指标，迭代到独立验收整题准确率至少95%。

## 验收口径

- 主指标：完整答对题数 / 全部有效验收题数。关键条件遗漏、对象或版本混淆、无依据断言、服务错误均算失败；拒答题需正确说明知识或实时状态缺口。
- 分别报告可回答题准确率、拒答题准确率、引用证据覆盖、检索证据Recall@5、延迟和模型usage。不得将检索命中率或0/0.5/1评分均值当作整题准确率。
- 样本按文档/近似主题分组后划分开发与验收，运行前冻结哈希。开发集用于迭代；最终配置冻结后才运行验收。验收失败后若查看bad case并优化，该批转为回归集，另取未使用题验收。
- 评测集由AI按原文编写，未经过运维专家认证；自动语义评分明确标注LLM评审。所有失败、评分分歧与至少20%的成功题进行证据复核，复核也注明执行者。
- 保留所有轮次，不删难题、不修改标签追求达标、不把REPLAY结果算作真实模型质量。
- 修复通过Go公开HTTP接口及外部模型适配器回归；使用真实临时文件存储，模拟仅限外部依赖。
