# 06: QA-06 建立首批问答验收基线

**Task:** QA-06

**Blocked by:** 03 (QA-03), 04 (QA-04), 05 (QA-05)

**Status:** ready-for-agent

**Spec:** [总体设计](../../../docs/design/hardware-operations-agent-overall-design.md) · [Go + Eino 技术设计](../../../docs/design/hardware-operations-agent-technical-design.md)

**交付行为：** 使用 Go 评测入口与 `testing`、`httptest`，对指示灯、错误码、配置和状态查询运行可重复评测，形成可供运维人员复核的报告。

**验收条件：**

- [ ] 样本含标准答案或可接受结论、适用设备版本、必要引用和不可接受回答。
- [ ] 多型号、多版本、资料冲突、数据缺失及多轮换设备均被覆盖。
- [ ] 报告分别给出答案正确性、引用支持性、版本适用性、召回效果与耗时。
- [ ] 结构化流程验证与真实模型效果评分分开呈现。
- [ ] 记录失败样本、知识修订和模型配置，形成诊断阶段可复用的基线。
