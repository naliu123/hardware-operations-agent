# 09: EV-01 高优先级告警自动诊断并关联拓扑

**Task:** EV-01

**Blocked by:** 08 (DX-02)

**Status:** ready-for-agent

**Spec:** [总体设计](../../../docs/design/hardware-operations-agent-overall-design.md) · [Go + Eino 技术设计](../../../docs/design/hardware-operations-agent-technical-design.md)

**交付行为：** 高优先级告警建立或关联事件，自动开展只读排查；根据有效拓扑追查共同依赖。

**验收条件：**

- [ ] 告警优先级按实际监控映射配置，重复通知追加至同一事件。
- [ ] 拓扑关系和时间重合只形成候选关联，共同原因证据满足后才合并。
- [ ] 反对证据可触发拆分，操作和审批仍对应原目标。
- [ ] 恢复后再发生成新事件；延迟到达的旧告警按实际发生时间归属。
- [ ] 自动事件需要命令或变更时保存待审核事项，等待处理对话。
