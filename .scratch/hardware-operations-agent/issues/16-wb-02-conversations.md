# 16: WB-02 多会话、历史上下文与删除

**目标：** 用户管理自己的会话，跨浏览器继续历史问答，长对话有界使用历史。

**Blocked by:** 15 (WB-01)

**Status:** done

**依据：** [规格](../../../docs/design/chat-workbench-spec.md) R06～R10；
[技术方案](../../../docs/design/chat-workbench-technical-design.md)第 5、7、11 节。

## 交付行为

提供新建、列表、切换、自动命名、重命名、历史读取和搜索。自动标题不得覆盖
用户手动标题。消息按序追加；同会话最多一条活跃响应，跨会话可以并行。

将实际历史问答纳入模型输入，使用有界的最近轮次和带来源范围的摘要；保留原始
历史。失败重试追加新尝试。删除先禁访和取消，再持久化清理消息及相关文件的任务。
附件与产物的具体清理将在 WB-04/WB-06 接入同一规则。

## 验收条件

- [x] 浏览器完成全部会话操作；刷新和另一浏览器登录后内容、标题与顺序一致。
- [x] 搜索覆盖自己的标题、问题及最终答案，不泄露他人数据或已撤回草稿。
- [x] 两标签页并发提交与重复幂等请求不创建两条活跃任务，冲突保留未发输入。
- [x] 外部模型收到真实前轮上下文；跨会话、摘要失败及预算超限有明确反例。
- [x] 摘要记录覆盖范围和原引用，不将旧设备读数、失败输出变为当前证据。
- [x] 失败重试保留旧记录；自动命名失败不阻断聊天。
- [x] 删除正在运行的会话立即禁访并取消，清理失败可重试，迟到答案不复活会话。
- [x] 真实 PostgreSQL 的并发及重启测试通过；公开模型流程使用外部 Adapter。
